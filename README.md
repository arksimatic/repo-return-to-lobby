# repo-return-to-lobby

R.E.P.O. mod that lets the host go back to the lobby mid-run, so new players can join. Type `/lobby` in chat, then press Start to carry on from where the run was saved. Loot from the current level is lost.

## Install (Gale)

Copy `ReturnToLobby.dll` to:

```
%APPDATA%\com.kesomannen.gale\repo\profiles\<your profile>\BepInEx\plugins
```
